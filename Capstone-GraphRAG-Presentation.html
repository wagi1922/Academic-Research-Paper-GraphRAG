04 · QUERY PIPELINE

End-to-End Flow: Hybrid Search + Grounded Synthesis

Query Pipeline membedakan GraphRAG dari RAG standar: hybrid search (vector + graph traversal) + grounded synthesis dengan citation validation.

Target latency P95 < 10 detik untuk query kompleks multi-hop.

sequenceDiagram participant User participant API as API Gateway participant Orch as QueryOrchestrator participant Vec as VectorSearch participant Gph as GraphTraversal participant Ctx as ContextBuilder participant LLM as LLMSynthesizer participant Val as CitationValidator participant DB as Neo4j User->>API: POST /api/v1/query {query, top_k=5, depth=2} API->>Orch: execute(query, params) Orch->>Vec: search(query, top_k) Vec->>DB: CALL db.index.vector.queryNodes('chunk_vector_idx', $top_k, $embedding) DB-->>Vec: List[Paper] (seed papers) Vec-->>Orch: seed_papers Orch->>Gph: traverse(seeds, depth) Gph->>DB: CALL apoc.path.subgraphAll(seeds, {maxLevel: $depth}) DB-->>Gph: Subgraph (nodes + edges) Gph-->>Orch: subgraph Orch->>Ctx: build(query, seeds, subgraph) Ctx-->>Orch: prompt_context Orch->>LLM: synthesize(prompt) LLM->>OpenRouter: POST /v1/chat OpenRouter-->>LLM: Answer + citations LLM-->>Orch: raw_answer, citations Orch->>Val: validate(citations) Val-->>Orch: validated_citations, grounding_score Orch-->>API: {answer, sources, graph_path, grounding_score, latency_ms} API-->>User: 200 OK JSON

ANTICIPATED QUESTION

"QA gold 30-40 pairs — cukup untuk statistical significance?"

Ya, paired t-test butuh ~20+ untuk power 0.8. Target 40. Jika reviewer minta lebih: "Kami siap generate synthetic QA dari corpus via LLM + manual verify."

Paired t-test power analysis: n=30, α=0.05, power≈0.85

E4 Ablation adalah eksperimen paling kritis — membuktikan GraphRAG signifikan lebih baik dari vector-only dengan statistical rigor.
